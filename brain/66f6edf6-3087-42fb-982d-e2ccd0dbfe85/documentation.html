Dokumentasi Sistem

InsureMind Agent Platform (ASM Academy)

1. Product Requirements Document (PRD)

1.1 Latar Belakang & Tujuan

InsureMind Agent Platform (dikenal juga sebagai ASM Academy) adalah platform berbasis web terintegrasi (SPA) yang dirancang untuk meningkatkan kompetensi, kepatuhan regulasi, dan efektivitas penjualan agen asuransi umum di Indonesia.

Tujuan utama sistem ini adalah:

  • Gamifikasi Pelatihan: Menyediakan platform Learning Management System (LMS) mandiri dengan penghargaan koin karir, peringkat (leaderboard), dan lencana pencapaian.
  • Sertifikasi LSP: Memfasilitasi pendaftaran sertifikasi lembaga sertifikasi profesi (LSP) dan latihan ujian (tryout) secara digital.
  • Pendamping Kerja AI (AI Coach): Membantu agen menemukan rekomendasi produk asuransi yang tepat berdasarkan data SOP internal perusahaan secara instan menggunakan teknologi RAG (Retrieval-Augmented Generation).
  • Otomatisasi Penawaran (PPT Builder): Mempercepat proses pembuatan proposal presentasi formal yang mematuhi regulasi tarif premi OJK secara dinamis.

1.2 Target Pengguna & Peran (Roles)

Peran (Role) Deskripsi Fitur Utama dalam Sistem
Agen (Agent) Pengguna akhir yang menjual produk asuransi. Mengikuti modul LMS, kuis, pendaftaran kelas live training (RSVP), latihan tryout LSP, simulator premi OJK, AI Coach, pembuatan proposal PPTX, dan penukaran reward.
Trainer Pengajar/fasilitator kompetensi. Manajemen kelas training, pembuatan token absensi, publikasi kuis training, verifikasi nilai kuis, dan penerbitan sertifikat pelatihan resmi.
Admin Pengelola sistem dan operasional. Manajemen katalog produk asuransi dinamis (FAQ, link brosur), manajemen stok reward toko virtual, pengelolaan akun pengguna, pemantauan log transaksi, dan persetujuan klaim hadiah.
Pimpinan (Management) Pemantau kinerja tingkat tinggi. Dashboard monitoring total produksi agen, grafik performa bulanan, laporan sertifikasi LSP agen, status penyerapan reward, serta peringkat nasional/cabang.

1.3 Ruang Lingkup Fitur (Feature Scope)

  • Modul LMS Mandiri (Gamified Learning): Pembagian materi belajar dalam 3 tingkatan kesulitan (Basic, Intermediate, Advanced) berformat artikel, video, PDF rujukan, ringkasan, dan kuis kelulusan (skor >= 70%) untuk mendapatkan koin karir.
  • Sertifikasi LSP & Tryout: Pendaftaran tryout ujian sertifikasi profesi, player kuis latihan interaktif dengan pengatur waktu, riwayat skor, serta lencana tanda kelulusan aktif ("Certified") di halaman profil agen.
  • Sesi Live Training (LMS Kelas): Pendaftaran kehadiran (RSVP), verifikasi kehadiran real-time menggunakan Token Absensi (4 digit angka) yang diterbitkan oleh Trainer kelas, serta penerbitan sertifikat digital resmi.
  • Toko Reward Virtual (Gamification Store): Penukaran koin agen dengan voucher virtual terproses otomatis (e-wallet, pulsa), voucher fisik (menunggu persetujuan admin), atau item kosmetik profil (Bingkai Emas Premium).
  • AI Insurance Coach & Product Finder (RAG):
    • Client-side RAG: Pengguna mengunggah berkas PDF pendukung yang disimpan di IndexedDB browser untuk disematkan dalam prompt chat dengan Gemini secara langsung.
    • Server-side RAG: Pencarian produk asuransi berbasis data SOP internal dari database materi_pdf_text.json melalui API backend.
  • Auto Proposal PPTX Builder & Simulator: Perhitungan premi asuransi kendaraan bermotor dan properti sesuai tarif standar Surat Edaran OJK No. 6/SEOJK.05/2017, serta ekspor file PowerPoint (.pptx) rincian quotation.

3. Arsitektur Sistem (System Architecture)

Sistem ini menggunakan arsitektur Client-Server terpisah (Decoupled Architecture). Sisi klien bertindak sebagai Single Page Application (SPA) mandiri yang menanggung rendering dan penyimpanan data sementara (LocalStorage & IndexedDB). Sisi server (Express API Server) beroperasi tanpa state (stateless) untuk melayani kalkulasi dokumen (.pptx) dan pembungkusan API kecerdasan buatan.

3.2 Komponen Teknologi

  • Frontend: HTML5 (struktur SPA berbasis section display toggling), Vanilla CSS (tata letak grid modern premium, tema navy gelap, visual glassmorphism), dan Vanilla JS (logika DOM, routing, IndexedDB, dan LocalStorage).
  • Backend: Node.js, Express.js (API routing), CORS middleware, dan PptxGenJS (PowerPoint file composer).
  • AI Core: Google Gemini 1.5 Flash API (Model generatif teks-ke-teks dengan dukungan multi-media untuk stuffing PDF).

4. Teknikal Desain (Technical Design)

4.1 Struktur Folder Proyek

  • server.js: Backend API server Express.js untuk endpoint generate PPTX dan RAG produk asuransi.
  • app.js: Pengendali utama frontend (SPA router, logic kuis, live training, reward virtual).
  • ai-coach.js: Pengendali RAG client-side (IndexedDB file parser & integrasi Gemini SDK).
  • data.js: Database lokal mock (materi default, riwayat, toko reward).
  • index.html: Antarmuka tunggal pengguna web (layout desktop & mobile).
  • asm-style.css: Berkas CSS utama tema premium navy & glassmorphism.
  • materi_pdf_text.json: Dataset teks penawaran / RAG server-side.

🛡️ Integrasi Klien Selesai
Seluruh fungsi frontend (downloadProposalPptx(), openPptxBuilderTab(), switchProposalTab()) telah diintegrasikan di dalam app.js.
